# 0.5 Websocket authentication

- Decided by: earlier sessions (moved from TODO.md section 0)

No CSRF token. Session cookie
`SameSite=Strict` + `http.CrossOriginProtection` on every chain +
`OriginPatterns` (`APP_URL` host) on websocket accept replace the
original `?csrfToken=` check. Consequence: GET handlers must never
change state (rule in `CLAUDE.md`).
