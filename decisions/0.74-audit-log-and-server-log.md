# 0.74 Audit log and server log

- Decided by: user (an audit log keeping a year of security events, viewable
  in the admin area; the current server log viewable in the admin area);
  Claude (events, table, messages)
- Date: 2026-10-21

Audit log:

- Table `audit_log` (`id`, `created_at`, `event`, `user_id` without a
  foreign key, `username`, `address`, `details` JSON text), index on
  `created_at`. `components.Audit.Record(ctx, event, actor, details)` writes
  it; a failed write is logged and never fails the action it records.
- Events: `login_succeeded`, `login_failed`, `login_locked`,
  `passkey_login_succeeded`, `passkey_login_failed`, `logout`,
  `password_changed`, `password_attempts_locked`, `passkey_registered`,
  `passkey_deleted`, `user_created`, `user_updated`, `user_deleted`,
  `backup_target_created`, `backup_target_updated`,
  `backup_target_deleted`, `backup_created`, `backup_deleted`,
  `backup_downloaded`, `tag_updated`, `tag_deleted`,
  `file_visibility_changed_by_admin`, `file_deleted_by_admin`. Details
  never hold a password.
- The periodic task `cleanup-audit-log` (daily) deletes entries older than
  365 days.
- Websocket `settings/getAuditLog{filters{event, username, from, to}, page}`
  → `getAuditLogResponse{records: Paged<AuditLogRecord>, events}` (20 per
  page, newest first; `events` lists every distinct event for the filter),
  permission `canViewAuditLog`. Settings → Audit log in the frontend.

Server log:

- `logger.Buffer` keeps the last 1000 log lines in memory (every line also
  goes to stderr as before); `settings/getServerLog` →
  `getServerLogResponse{lines}`, permission `canViewServerLog`. Settings →
  Server log shows them with a 10 s refresh. Log lines now carry the date.
- The buffer always holds the coloured form of a line (ANSI codes 31, 32,
  33, 90 and the reset), whatever `SHOW_LOG_COLORS` says about the terminal;
  the page maps the codes to the theme colours (`src/lib/ansi.ts`) and shows
  nothing else of them.
- Both permissions belong to the admin role only and count as settings
  permissions; `frontend/src/lib/rbac.ts` mirrors them.
