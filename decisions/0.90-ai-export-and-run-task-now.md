# 0.90 Assistant data export and running a periodic task now

- Decided by: user (the assistant can export the user's data with the same
  flow as the button; a Run now icon per periodic task that makes it due a
  second later so the run is recorded, also offered to the assistant, for
  admins only); Claude (details below)
- Date: 2026-10-21
- Amends 0.83 (export was never offered) and 0.55.

## Data export from the assistant

- The export flow moved from `ExportMyData` into the `data-export` store;
  its dialogs (confirmation, progress, download) are `DataExportDialogs` in
  the app layout, so they open from any page. `ExportMyData` is the card
  with the button. Closing the tab or signing out still cancels a running
  export; leaving the Data page no longer does, since the progress dialog
  is modal.
- `export_my_data` is a browser tool: it opens the same confirmation,
  asks for the password through the protection lock when it is locked, and
  answers once the export has started (or was declined, failed, or another
  one is running). It does not wait for the end: an export can outlast the
  turn's 10 minute wait for tool results, and the download link is only
  for the user. No Allow / Deny step; the confirmation dialog is the
  confirmation.

## Run now

- New permission `canRunPeriodicTasks` (admin), in `rbac` and
  `src/lib/rbac.ts`.
- `settings/runPeriodicTask` `{task_identifier}` (not in the original)
  answers "Periodic task not found." for a task without a schedule row,
  otherwise stores `next_run_at` = now + 1 s, publishes
  `eventbus.PeriodicTaskRunRequested`, records
  `periodic_task_run_requested` in the audit log, answers
  `runPeriodicTaskResponse` `{task_identifier, next_run_at}` and sends
  `dataChanged` for `periodicTask` to the other viewers.
- The scheduler keeps its schedule in memory, so it subscribes to that
  event: requests are kept under a mutex and wake the loop, which applies
  them between ticks. The loop now waits until the earliest next run
  instead of always the next minute. The run itself is an ordinary run:
  recorded in `periodic_task_run`, rescheduled with the task's own
  schedule, and `PeriodicTaskRan` refreshes the list.
- Settings → Tasks shows a play icon ("Run now") to those with the
  permission, with an info toast "<task> will run in a moment.".
- The assistant's `run_periodic_task` (`canRunPeriodicTasks`) asks for
  Allow / Deny first, since tasks back up the database or delete expired
  data.
