# 0.81 Editor toolbar replaces the insert dialog

- Decided by: user (Write/Preview, width and lock beside the folder line,
  Write/Preview as icons; no insert dialog: its items become toolbar icons,
  table, file, note list and note link open their own dialog, the rest
  insert directly; link and image get placeholders and use selected text;
  H1 to H6 buttons); Claude (details below)
- Date: 2026-10-21
- Amends 0.38 and 0.65 (toolbar), 0.80 (placement of the width toggle).

- The row under the tags holds the folder path on the left and, on the
  right, the Write/Preview icon switch (`ButtonGroup` with `icons-only`),
  the width toggle (desktop only) and the lock. The top bar keeps Close,
  Save and the more menu, which still has preview and protect for phones.
- Toolbar groups: bold, italic, inline code | H1 to H6 | list, checklist |
  link, image | table, file, note list, note link (each opens
  `InsertItemDialog` with its old panel) and table of contents (inserted
  directly). The toolbar is disabled in preview.
- `setHeading` sets the level of every selected line, replacing an
  existing one; the same level again turns the lines back into paragraphs.
- Link and image insert `[Link text](https://)` and
  `![Image description](https://)`. Selected text becomes the label or
  description and the URL placeholder is selected; a selected URL becomes
  the target and the label placeholder is selected. The Ctrl shortcuts use
  the same commands.
- `InsertDialog`, its Alt+I shortcut and the heading, link, image and table
  of contents panels are removed; help and onboarding describe the toolbar.
