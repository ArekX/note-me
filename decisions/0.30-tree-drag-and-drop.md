# 0.30 Tree drag and drop

- Decided by: user (use Shopify Draggable), Claude (how it is wired)
- Date: 2026-10-19

The sidebar tree uses `@shopify/draggable` (`Draggable` core with its mirror
and auto scroll plugins) instead of native HTML5 drag events. It is approved
under 0.11 and replaces the original's `useDragManager` with
`composables/useTreeDrag.ts`.

- `Droppable` and `Sortable` are not used: they move DOM nodes that Vue owns.
  The plain `Draggable` only clones the source while dragging and puts the
  original back on drop; the tree store then moves the node and Vue renders it.
- Containers are the tree list and the "Top Level" bar. Every item carries
  `data-tree-key`; only rows with `data-drag-handle` start a drag (groups now,
  notes in item 4). A press must move 8 px before a drag starts, so clicks
  stay clicks; the click that browsers fire right after a drop is ignored.
- Hovering a note targets the note's group; hovering the bar targets the top
  level. `treeStore.canDropTo` refuses the group itself, its descendants
  (0.9.x, client side), its current parent and notes. The server checks too.
- The mirror is appended to `body` (the sidebar clips overflow) and drops the
  group's children, so dragging an open group does not drag a tall copy.

- Item 4: note rows are drag handles too; the store action is `dropItem`
  (0.36).
