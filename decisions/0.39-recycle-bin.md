# 0.39 Recycle bin

- Decided by: Claude (TODO item 7)
- Date: 2026-10-19

- Workers do not import `internal/http`; the expiry task publishes
  `eventbus.NoteFullyDeleted` and the websocket handlers push it (0.40
  replaced the original `tasks.Notify` push functions).
- `FullyDeleteNotes` also removes `note_share_user` rows (0.9.f). The
  notifications that point at a deleted note are left for item 11, which
  adds the notification repository; its `FullyDeleteNotes` change is noted
  there.
- `RestoreDeletedNote` replaces all of the user's `group_note` rows for the
  note with one top-level row (0.9.g), and only when the note really was
  deleted (the original removed grouped rows even for a live note).
  `restoreDeletedNote` answers `restored_note: null` when nothing was
  restored instead of returning the note anyway; a successful restore goes
  to all of the user's tabs (`RespondToUser`), as does `fullyDeleteNote`.
- `RemoveExpiredDeletedNotes` only picks notes with `is_deleted = true` and
  runs the select and the cascade in one transaction.
- The recycle bin item waits for the `fullyDeleteNote` response instead of
  dispatching it without one.
- DevControl's "fully deleted" trigger now pushes `fullyDeleteNoteResponse`
  (what the browser receives) and removes the note from the mock state; it
  used to push the backend-only `notifyFullyDeletedNote`.
