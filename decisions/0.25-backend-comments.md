# 0.25 Backend comments

- Decided by: user
- Date: 2026-10-19

Go code (tests included) keeps a comment only where the code cannot show what
is happening or why: non-obvious reasons, outside constraints (library,
driver, OS, container image, external formats, protocol and string enum
values), security invariants, magic numbers and the origin of test vectors.
Comments that narrate code, repeat assertions or restate obvious decisions are
removed. The rule is in `CLAUDE.md` under Comments.

Extended to the frontend by 0.29.
