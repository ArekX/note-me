# 0.21 Host timezone

- Status: replaced by 0.24 (host timezone detection was removed)

- Decided by: user (backend must be cross-platform) and Claude (lookup order)
- Date: 2026-10-19

`timezone.Host()` returns the IANA name from `TZ` (works on every OS), else the
`/etc/localtime` symlink target (Linux, macOS, BSDs), else `UTC`. Go has no
portable lookup of the host's IANA name; on Windows it is `UTC` unless `TZ` is
set (a registry lookup would need `golang.org/x/sys/windows/registry` and a
Windows-to-IANA table, not approved). `time/tzdata` is embedded by
`internal/timezone` so zone validation works without a system zoneinfo
(distroless, Windows).
