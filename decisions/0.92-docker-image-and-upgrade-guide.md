# 0.92 Docker image name and the v1 upgrade guide

- Decided by: user (v2 is released as `arekxv/note-me`, the image v1 used,
  with an upgrade guide in `docs/` linked from the README and the release
  notes); Claude (details below)
- Date: 2026-11-27

- The release workflow, `Makefile` (`IMAGE`), the README and
  `docker-compose.example.yml` use `arekxv/note-me`; `arekxv/note-me-go`
  was the rewrite's working name and is no longer published. v2 is tagged
  `2.0.0`, after v1's last tag `1.6.0`.
- v1 users who pull `arekxv/note-me:latest` get v2, which refuses to start
  on their database until `noteme-upgrade` has run, so nothing is changed
  without the upgrade.
- `docs/upgrading-from-v1.md` is the upgrade guide: what changes, the
  Docker Compose steps (including `chown` to uid 65532, since the v1 image
  ran as root and the distroless image runs as `nonroot`) and the steps
  without Docker. The README keeps a short section that links to it.
