# 0.29 Frontend comments

- Decided by: user
- Date: 2026-10-19

The comment rule of 0.25 applies to the frontend too (TypeScript, Vue, CSS,
tests included): a comment stays only where the code cannot show what is
happening or why. JSDoc on exported identifiers and comments that narrate the
code are removed. File references to the original app stay until the last
TODO item (0.26), reduced to the reference itself. Extends 0.25; the rule in
`CLAUDE.md` under Comments covers both.
