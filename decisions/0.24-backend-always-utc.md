# 0.24 Backend always UTC

- Decided by: user
- Date: 2026-10-19
- Replaces: 0.21

- The backend always runs in UTC, whatever the host zone: `noteme`,
  `noteme-cli` and `noteme-upgrade` set `time.Local = time.UTC` first, and
  server-side time math (periodic task boundaries in
  `periodictask/next_at.go`) uses UTC explicitly so tests do not depend on
  the machine either.
- There is no host timezone detection. Users created without a browser (the
  first-run admin, `noteme-cli add-user`) get timezone `UTC`; the user changes
  it in their profile.
- Daily tasks (backup, expired deleted notes, expired share links) run at
  midnight UTC. The original ran them at the server's local midnight.
- `time/tzdata` stays embedded for validating user timezones without a system
  zoneinfo database.
