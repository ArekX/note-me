# 0.13 Transactions in the repository

- Decided by: earlier sessions (moved from TODO.md section 0)

Closure only,
`repo.RunInTransaction(ctx, func(tx *Repository) error)`, no public
begin/commit. `Repository` keeps `drivers.DB` plus a querier
(`Exec/Query/QueryRowContext`, satisfied by both DB and Tx), so every
method works inside or outside a transaction unchanged. Commit when fn
returns nil, rollback otherwise; calling it on a tx-bound repository
joins the outer transaction (no savepoints). Inside fn use only `tx`
(the single sqlite connection deadlocks on the outer repo), keep fn to
database work and push websocket messages after it returns. Implemented
in `repository/helpers.go`; rules are in `CLAUDE.md`.
