# 0.82 Audio and video players, file double-click, dialog sizes

- Decided by: user (fix the protection lock bug; padding under dialog
  titles; double-click inserts a file by its type; audio and video
  extensions; insert dialogs fit their content up to 80%; tag input
  behaviour, Backspace removes a tag); Claude (details below)
- Date: 2026-10-21
- Amends 0.81.

- Extensions `{:audio|<URL>}` and `{:video|<URL>}` render a native player
  with controls (`preload="metadata"`), at most 20 of each per note. Only
  `/file/...` and http(s) addresses play (`playableMediaUrl`); anything else
  shows an error box, so no other scheme reaches the element. Both are in
  the `{:` autocomplete and the markdown syntax help.
- Double-clicking a file in the insert file dialog inserts it and closes
  the dialog: images as an image, audio and video as a player, everything
  else as a download link (`getFileMarkdown`). Files dropped or pasted into
  the editor use the same rule. "Insert as" keeps every option and adds
  Audio player and Video player. In the file picker a double-click no
  longer opens the file in a new tab.
- Insert dialogs use `dialog-fit`: as wide as their content, at most 80vw
  (the table grows with its columns; file, note list and note link panels
  have their own widths). Dialog titles get padding below them.
- Protection lock: the stored password is obfuscated by shifting its UTF-8
  bytes instead of its characters, with a `b1:` prefix. Shifting characters
  could produce a lone surrogate that the encoder replaced, so a reload
  could restore a wrong password. A value without the prefix is ignored and
  that session starts locked.
- Tag input in the editor (`TagInput` with `commit-on-separator`): the
  suggestion popup opens on the first typed character, is teleported to
  `body` (or the open `<dialog>`) and placed under the tag being typed,
  inside the window. A space, comma or Enter turns the text into a chip and
  the same input keeps focus; `TagChipsInput` no longer re-keys the input
  after each tag. Picking a suggestion keeps focus too. Backspace in the
  empty field removes the last tag (user's request), one per press. The
  field fills the rest of the row and a click on the row focuses it.
  Suggestions leave out tags already added (the chips, or in the search
  box the other tags in the text), compared without case.
