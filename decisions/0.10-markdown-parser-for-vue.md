# 0.10 Markdown parser for Vue

- Decided by: earlier sessions (moved from TODO.md section 0)

`markdown-it` + `markdown-it-footnote`
(+ `@types/markdown-it`) instead of vendoring the original's
pulldown-cmark WASM (`lib/rusty-markdown`). Benchmarked in Node 24: ~5×
faster than the WASM at every realistic note size (0.2 vs 1–1.6 ms for
4 KB, 9 vs 40 ms for 135 KB), ~47 KB vs ~122 KB gzipped, no
WASM/top-level-await init. micromark was rejected (4–8× slower than the
WASM). Known caveat: `markdown-it-footnote` slows down sharply with many
footnotes (74 vs 43 ms at 400 in one note); replace it with an own
footnote rule if that ever matters. Port details in item 4.

Implementation details and the differences from the original are in 0.35.
