# 0.68 Frontend component refactor

- Decided by: user (TODO item 26: move reusable Vue code into components,
  remove duplicates, keep files under 500 lines); Claude (details below)
- Date: 2026-10-20

- Every frontend file stays under 500 lines. Splits:
  - `stores/tree.ts`: node bookkeeping (attach, detach, set children,
    add/update nodes, group path, snapshot) moved to `stores/tree-nodes.ts`;
    `stores/tree` re-exports `TreeNode`, `nodeKey`, `nodeFromRecord`,
    `noteNode` and `ROOT_KEY`. Group and note updates and moves share one
    request each.
  - `assets/styles.css`: note editor, markdown, diff and mermaid styles
    moved to `assets/notes.css` (imported at the top of `styles.css`).
    Unused rules (`.icon-menu`, `.passkey-sign-in`,
    `.default-onboarding-wrapper`) removed.
  - The test-only mock backend: sharing and reminder handlers in
    `handlers/note-sharing.ts`, helpers in `handlers/note-helpers.ts`, note
    fixtures in `notes-fixture.ts`.
- New shared components: `IconButton` (icon-only row actions), `Badge`,
  `Callout` (`Alert` builds on it), `FormField` (label + validation errors
  for `Input` and `DropdownList`, which take `validation` and `path`),
  `UserAvatar`, `notifications/UnreadBadge`, `notes/NoteRow` (note rows in
  sidebar lists, search and the dashboard), `sidebar/SidebarList`
  (reminders, shared and recycle bin lists). `DashboardCard` shows the
  loader and the empty text itself; `SideTabPanel` owns its mobile toggle
  and height; `ButtonGroup` is generic over its ids and replaces the two
  hand-built copies; `FileManager` uses `Table`. The unused `Panel` and the
  never-passed `labelColor`/`color` props are gone.
- New shared helpers: `toastStore.reportError(error, prefix?)`,
  `validation.setServerErrors(error)`, `usePagedData(load)` with
  `changePage` and `loadFirstPage`, `useLoadMore().reload`,
  `useActiveNote`, `stores/groups` (`findGroups`, `getGroup`),
  `lib/navigation` (sidebar sections and profile tabs), `lib/initials`,
  `lib/unix-time`, `previewKind` in `lib/file-kind`, `apiErrorMessage` in
  `lib/api`, `isNoteWindowType` in `components/notes/note-windows.ts`.
  `TimeAgo` formats through `useTimeFormat`; `useDebouncedCallback` clears
  its timer when its scope ends, and `TagInput` uses it.
- Left as they are because the copies differ more than they share: the
  confirm-delete flows (different error texts, reload and paging rules),
  the note loading pages (socket, API and group errors), the progress
  dialogs, `InsertImage`/`InsertLink`, the two `MoreMenu`s and the search
  filter chips.
- Small visual changes from sharing: the shared note rows use the same
  padding everywhere (the dashboard's recently opened list was `py-2`),
  `NoteShare`'s protected warning and `Alert` use the `Callout` padding,
  form errors sit directly under their field, and the files visibility
  filter is a `ButtonGroup`.
