# 0.88 One file browser with grid and list views

- Decided by: user (grid and list view in the insert file dialog and the
  file lists, grid by default in the insert dialog and list elsewhere,
  switchable; the insert dialog gets the file list filters and the upload
  dialog); Claude (details below)
- Date: 2026-10-21
- Amends 0.65 (file filters) and 0.78 (upload dialog).

- `FileManager` (profile and Settings file lists) and `FilePicker` (insert
  file dialog) are built from the same parts: `FileFilters` (search, owner
  for admins, type, visibility, Clear and the Grid / List switch),
  `FileGrid` (the `FileItem` cards), `FileTable` (the table) and
  `useFileSelection`.
- Selection works the same in both views: click picks one file, Ctrl+click
  adds or removes one, the list's checkboxes toggle and select a page.
  Double-click views the file in the file lists and inserts it in the
  insert dialog. The insert dialog keeps files picked on other pages; the
  file lists act on the shown page only.
- The insert dialog's Upload button and dropped files open
  `UploadFilesDialog`, like the file lists.
- In the file lists the grid items are `glass-card` cards (a selected card
  is outlined, since the card sets its own border and shadow); the insert
  dialog keeps the plain bordered tiles.
- The chosen view is not remembered; each opening starts on its default.
