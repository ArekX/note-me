# 0.38 Editor tooling and markdown extensions

- Decided by: Claude (TODO item 6)
- Date: 2026-10-19

- Mermaid is imported dynamically (`lib/mermaid.ts`, `loadMermaid`) the
  first time a diagram is shown, so notes without diagrams do not download
  it; the theme is the original's. A diagram that fails to render shows its
  source text (the original left it there too, with an unhandled rejection).
  highlight.js is the full bundle, imported statically as in the original.
- `HighlightedCode` and `MermaidDiagram` take the code as a prop and render
  through `v-html` (highlight.js escapes its input; mermaid runs with its
  default `strict` security level) instead of rewriting the DOM after mount,
  so they update when the text changes.
- The insert panels are Vue components with a `noteText` prop and an
  `insertDataChange` event; their definitions (name, icon, insert buttons)
  live in `components/notes/insert/insert-components.ts`. The "Insert As"
  dropdown is built but only shows once a panel has more than one button
  (the File panel, item 14).
- `DropdownList` (`<select>` by index, `v-model`) is introduced here for the
  heading level instead of in item 17.
- The CodeMirror paste handler only intercepts a paste that contains files
  when the text area is given an `onPasteFiles` handler; until item 14 adds
  uploads, pasting files falls through to CodeMirror's default.
- Hotkey sets `noteTextArea` and `insertDialog` live in `useHotkeys` next to
  `noteEditor`; the editor keymap is built from the `noteTextArea` set.
- Fixes over the original: `getLinkMarkdown` / `getImageMarkdown` escape
  every `(` and `)` in the URL (the original replaced only the first of
  each); the table output no longer empties the grid's first row
  (`rows.shift()` mutated the panel state).
- Kept from the original: the "unavailble" and "pleaase" typos in
  user-visible text, note-list autocomplete offering top-level groups only.
- Amended by the user (2026-10-21): `{:note-link|<id>}` renders as a small
  inline card (`.note-link` in `notes.css`: note icon, title cut with an
  ellipsis, rounded border, card shadow) instead of the thick bordered box;
  a missing note is a red, disabled card. The card is a button, so it can
  be reached with the keyboard.
- Amended by the user (2026-10-21): a link to a note in the recycle bin is a
  dashed, muted card with the recycle icon, a struck-through title and "In
  recycle bin"; it opens the recycle bin in the sidebar (on a phone, the
  menu). `getNoteDetails` takes `include_deleted`, which returns the owner's
  deleted notes (never a share recipient's) with `is_deleted`. The card
  follows delete, restore and full delete responses.
