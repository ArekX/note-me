# 0.7 Websocket error contract

- Decided by: earlier sessions (moved from TODO.md section 0)

Fix both original quirks (DB-worker
errors without a `message` field; parse/size errors sent with a *new*
requestId, so the client timed out). Every error is `{requestId,
namespace:"system", type:"error", message}` with the failing request's
id and a non-empty `message`. Only a frame too broken to read an id
from gets a fresh id.
