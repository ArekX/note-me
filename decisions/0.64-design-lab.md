# 0.64 Design lab

- Decided by: user (5 visual style options and 3 sidebar options to choose
  from, the tree stays as it is, mobile must be touch friendly, everything in
  one folder that can be deleted); Claude (location, routes, contents)
- Date: 2026-10-20

- The options live in `frontend/src/design-lab` and nowhere else. The router
  spreads `designLabRoutes` from `@/design-lab/routes`, which is empty unless
  `import.meta.env.DEV`, so production builds contain none of it. Removing
  the lab is deleting the folder and those two lines in `src/router/index.ts`.
- Pages: `/design-lab` (index), `/design-lab/style-1` to `style-6` (Graphite,
  Aurora glass, Editorial paper, Tonal soft, Terminal, Aurora night) and
  `/design-lab/sidebar-rail`, `sidebar-account`, `sidebar-dock` (A, B, C).
  They sit outside `/app`, need no session or websocket and use static
  fixtures from `design-lab/fixtures.ts`, not the stores.
- After the first round the user picked the icon rail (A) and Aurora glass
  (2), darker and close to the current background: style 6 "Aurora night"
  (`dl-theme-aurora` plus `dl-theme-aurora-night`: the Aurora colours with a
  darker flat overlay, dark mode only, no gradients anywhere) and
  `/design-lab/rail-aurora`, the rail layout in that style with home,
  note, note edit, administration (the real settings tabs) and the
  component gallery in the main area (`sidebar/night/`). Style 2 keeps its gradients as the
  reference.
- Style pages render one shared gallery (`StyleShowcase.vue`, `dl-*` classes)
  under a theme class from `themes.css`, each with dark and light tokens.
  Fonts load from Google Fonts at runtime on these pages only; the chosen
  font gets self-hosted when it is applied.
- Sidebar pages draw a static copy of the current tree (`LabTree.vue`). They
  switch to the phone layout below 768px of their own width, so the "phone"
  frame on desktop and a real phone show the same thing.
- When the redesign is applied (not in the lab), the add note / add group
  buttons above the tree become context aware: with a group selected they add
  inside it, with a note selected they add next to it in its parent group,
  otherwise at the top level (user). How to get back to the top level with
  something selected is decided then.
- The mock control plane link is not part of the redesigned menus (user);
  in mock mode it stays reachable at `/app/dev`.
- The lab was deleted once the redesign was applied (0.65, user).
