# 0.46 Sharing

- Decided by: Claude (TODO item 12)
- Date: 2026-10-19

- New message `notes/getSharedNote{id}` → `getSharedNoteResponse{record:
  PublicSharedNote}` for the "shared with me" page, which the original
  loaded on the server (like `getNote`, 0.34). Not shared or deleted:
  "Requested note not found."; protected: "This note is protected by its
  owner and cannot be viewed." (the original route's texts). A protected
  note's text is never sent to anyone but its owner, here or on
  `GET /api/public/{identifier}`.
- `SetUserShare` ignores ids of missing or deleted users and the owner's
  own id, and returns only the users that were newly added; the original
  inserted whatever ids it got. Each new recipient gets a `note-shared`
  notification through `eventbus.NotificationCreated` (0.45) after the
  response is sent, as in the original.
- `FindUserSharedNotes` returns up to `min(limit, 10)` (0.9.a). The sidebar
  list asked for 5 while treating fewer than 10 as the last page, so it
  never paged; it now asks for and pages by 10. The dashboard widget still
  asks for 5.
- Setting a reminder is allowed on a note shared with the user
  (`SharedNoteWithUser`, which also ignores deleted notes).
- `findPickUsers` pages by 5 and answers an empty page while both filters
  are shorter than 2 characters after trimming, as in the original. The
  picker searches again after every add or remove, so a user just added
  drops out of the results.
- No generic `Picker` component: Vue templates switch with `v-if`.
  `api.getPublicNote` serves the public page; in mock mode it reads the
  fixture's link shares (`mockPublicNote`) the same way the session mock
  works. A link's expiry is the chosen date at UTC midnight, as the
  original parsed it.
- `ViewNote` gains `readonly`, `shareMode`, `disableTagLinks` and `author`.
  In `shareMode` "everyone" (public page) it registers no websocket
  listener, as the page is anonymous.
