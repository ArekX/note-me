# 0.60 Finish line

- Decided by: user (no release or Docker run in this item; comment file
  references removed here, 0.26); Claude (the rest, TODO item 22)
- Date: 2026-10-19

- Compatibility: `cmd/noteme-upgrade/compat_test.go` builds a database the
  way the Deno app leaves it (kysely migration table, a password hashed by
  the original's bcrypt library, a key and protected note in the old
  encryption format, file blobs, a passkey, a backup target), runs
  `noteme-upgrade`, starts the Go server on it and checks login with the old
  password, decrypting the protected note over the websocket, serving an
  extracted file from `FILES_LOCATION`, the new migration being applied with
  old passkeys removed, and a backup zip containing the file. A copy of a
  real database from the Deno app was also upgraded, migrated with
  `noteme-cli migrate-up` and served by the binary (health, private file
  redirect to login, error page redirect).
- `noteme-cli healthcheck` (used by the compose example) requests
  `/api/health` on `SERVER_ADDRESS` (loopback when it is `0.0.0.0` or empty)
  and `WEBSERVER_PORT` with a 5 s timeout, exits 0 or 1, and never opens the
  database. The optional `migrate-up/down [amount]` parity is left out.
- Docker: the stale `EXPOSE 8080` and `-p 8080:8080` in `make docker-run`
  are gone; the image already embeds `time/tzdata` and creates
  `/app/data`, `/app/backup`, `/app/files` and `/app/temp` for `nonroot`.
  `/app/temp` stays inside the container (0.48); data exports and backup zips
  are built there before they are stored.
- Only SQLite is supported: `DATABASE_DSN` with another type now fails at
  startup instead of being opened as a SQLite file path. The `<type>://`
  form stays.
- Cleanup: the unused `PagePlaceholder` component and the stale `TODO`s are
  gone. The remaining `isMockMode` branches are the HTTP seam of mock mode
  (login, session, public notes, passkeys, the socket transport) and stay.
  Comments that only named a file of the original app or of this repository
  are deleted, the others keep their text without the path (0.26).
- Quality gate: `make check test` (with `-race`) as in CI; the frontend
  `test:coverage` script works now that `@vitest/coverage-v8` (approved in
  0.11) is installed. `npm audit` reports 2 low severity issues in
  production dependencies; not fixed with breaking upgrades.
- Release (tag, image build, compose end to end) is not done in this item.
