# 0.41 One package per websocket namespace

- Decided by: user (package per namespace); details by Claude
- Date: 2026-10-19

- Replaces the single `handlers.Register(hub, repo, bus)` list (0.32, 0.40).
  Each namespace is a package under `internal/http/websocket/handlers/`
  (`groups`, `notes`, `tags`, `tree`; later items add theirs). Each has a
  `Namespace` type holding only what it uses, `New(c *components.Components)`
  and `Register(hub)`, which lists its own `hub.Handle` / `hub.HandleBackend`
  routes and event bus subscriptions.
- `api.NewHub` creates the hub and hands all namespaces to
  `hub.RegisterNamespaces(tree.New(c), groups.New(c), ...)`, which calls
  each one's `Register`; any type with `Register(*websocket.Hub)` satisfies
  `websocket.Namespace` (user).
- Namespaces do not import each other; a helper two namespaces need moves
  to a lower layer or is duplicated.
- The websocket test server and request helpers are the package
  `handlers/handlerstest` (`New(t, namespaces)` where `namespaces(c)`
  returns the `[]websocket.Namespace` under test, `Server.Dial`,
  `Server.AddUser`, `Server.CreateNote`, `Request`, `Read`, `Send`,
  `Encode`, `AdminID`). The namespaces a test talks to are registered before
  any connection exists.
