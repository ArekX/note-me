# 0.20 First-run bootstrap

- Decided by: Claude
- Date: 2026-10-19

The initial `Administrator` / `admin` / `admin` user (role admin, reset
required, timezone `UTC` per 0.24) is created when the migrator had no executed
migrations before `Up`, both in server startup (`Components.Initialize`) and in
`noteme-cli migrate-up`; otherwise migrating from the CLI first would leave a
database with no user. `noteme-cli add-user` creates an admin (timezone
`UTC`) with reset required and does not print the password.
