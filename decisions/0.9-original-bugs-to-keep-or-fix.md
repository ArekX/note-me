# 0.9 Original bugs to keep or fix

- Decided by: earlier sessions (moved from TODO.md section 0)

- 0.9.a `findUserSharedNotes` LIMIT is `min(limit, 1)` → always 1 row
  (sidebar "Shared with me" never pages). Fix.
- 0.9.b `searchSharedNotes` / `searchReminderNotes` outer query not
  scoped by user → other users' rows leak. Fix.
- 0.9.c `linkNoteWithTags` with empty `tags` is a no-op → tags can never
  be cleared. Fix.
- 0.9.d `updateNote` saves `is_encrypted` only when `title || text` is
  truthy; empty title/text not saved. Fix (save when key present).
- 0.9.e `deleteUserNotesByParentId` (group delete) soft-deletes notes
  without `deleted_at` → never expire from recycle bin. Fix.
- 0.9.f `fullyDeleteNotes` leaves `note_share_user` rows (and
  notifications) orphaned. Fix.
- 0.9.g `restoreDeletedNote` deletes grouped `group_note` rows but does
  not insert a root row → restored note missing from tree. Fix (insert
  `group_id NULL` row; UI text says "restored to the top level").
- 0.9.h Public/user share views and `getReadyReminders` do not check
  `note.is_deleted`. Fix.
- 0.9.i `fileExistsForUser` always true (`!== null` on `undefined`).
  Fix.
- 0.9.j `sendFileData` appends before size check and never checks the
  DB record exists/owned. Fix (handler.go TODO already says so).
- 0.9.k `updateProfileResponse` echoes passwords back. Fix (strip).
- 0.9.l `findTags`/`createTag` not permission-checked (`canReadTags`
  exists for that). Keep (every role has `canReadTags` anyway).
- 0.9.m Repeat reminder `next_at` computed from `now`, not previous
  `next_at` (drifts) and not minute-truncated after the first run. Keep.
- 0.9.n Role captured at websocket connect; stale after admin changes
  it. Fixed by 0.4: the connection's session is replaced on
  `sessionUpdated` pushes (item 2).
- 0.9.o `jobOwners` map leaks (never cleaned on finish/fail). Fix.
- 0.9.p Export note file names collide (`[^a-zA-Z0-9]` → `-`), no front
  matter, file has no `.zip` extension on disk. Keep names and no
  front matter. Fix: export file is written with a `.zip` extension
  (item 16).
- 0.9.q Backup copies the live SQLite file (no consistency guarantee).
  Fix: `VACUUM INTO` a temp file, then upload/copy that.
- 0.9.r Search `LIKE` input not escaped (`%`/`_` act as wildcards); group
  filter walks soft-deleted descendant groups. Fix escaping
  (`likeContains` exists); keep walk.
- 0.9.s Brute-force protector trusts the whole raw `X-Forwarded-For`
  value; counts successful logins; never resets on success. Fix: first
  hop only, optional trusted-proxy config.
- 0.9.t Admin password reset regenerates `encryption_key` → the user's
  protected notes become unreadable (documented in UI). Keep.
- 0.9.u Login page hides the normal "Sign in" button when WebAuthn is
  unsupported. Fix.
- 0.9.v Help/onboarding text says insert dialog is Ctrl+Q bottom-left;
  real is Alt+I bottom-right. Fix text.
- 0.9.w Periodic task badge text uses `last_successful_run_at` instead
  of `is_last_run_successful`. Fix.
- 0.9.x Drag/drop allows dropping a group into its own descendant;
  server `updateGroup` only checks "own parent". Fix both.
