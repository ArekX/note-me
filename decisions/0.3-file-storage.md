# 0.3 File storage

- Decided by: earlier sessions (moved from TODO.md section 0)

Uploaded files live on disk in `FILES_LOCATION`
(`Config.FilesDir`) as `<identifier>`, not in the database. The original
stores raw bytes in `file.data` (no base64), and `noteme-upgrade`
extracts them. Work is in items 14 (files), 16 (export), 19 (backups)
and 22 (compatibility test).
