# 0.79 Admin help topics

- Decided by: user (admin help topics visible only to admins); Claude
  (one page per settings tab, gating, names, header help button)
- Date: 2026-10-21
- Extends 0.58.

- The help window has one page per settings tab: `admin-backups`,
  `admin-periodic-tasks`, `admin-users`, `admin-tags`, `admin-files`,
  `admin-audit-log` and `admin-server-log`, listed after the user topics
  as "Admin: <tab>" (`SideTabPanel` has no section headings).
- Each admin topic carries its settings route and shows only when the user
  can open the settings area and has that tab's permission
  (`permissionForSettingsRoute`), so the topics follow `settings-tabs.ts`.
  The settings area check matters for Tags, whose tab permission
  (`canReadTags`) every user has.
- A help key the user cannot see (also one opened directly with
  `help.open`) selects the first visible topic instead; the hidden page is
  never rendered.
- The periodic tasks page renders the task list from
  `lib/periodic-tasks.ts` instead of repeating its names, schedules and
  descriptions.
- `PageHeader` takes an optional `help` key and then shows a help icon
  button next to the title that opens that topic; every admin screen passes
  its key.
