# 0.36 Note pages and editor

- Decided by: Claude (TODO item 4)
- Date: 2026-10-19

- Times are shown in the browser timezone, as the original did
  (`useTimeFormat`, `TimeAgo`). The profile timezone is only used where the
  server schedules per user (reminders, item 11).
- Navigation: `lib/redirect.ts` builds vue-router locations (`root`,
  `newNote`, `viewNote`, `editNote`). The original's propagation tickets are
  not ported: every save awaits its response before navigating. The dirty
  editor guards with `onBeforeRouteLeave` / `onBeforeRouteUpdate` ("Are you
  sure you want to discard changes?") and `beforeunload` instead of
  before-redirect listeners.
- The active tree row comes from the current route (item 3), so
  `useActiveNote` is not ported.
- `/app/note` redirects to the dashboard (`/app`). In the original `/app`
  redirected to `/app/note`, which showed the dashboard.
- `NotePage` loads the note with `getNote` (0.34) and re-keys the viewer or
  editor when the note id changes or a history revert replaces the note.
  Until item 8 a protected note shows "This note is protected." instead of
  its content.
- The `notes` and `tags` stores are typed socket calls without state; the
  stub fields (`activeNote`, `isProtectionUnlocked`, ...) are removed and
  item 8 adds the protection state it needs.
- `TagInput` follows tag changes pushed from other tabs; the original kept
  the tags it was mounted with.
- Notes move like groups: `MoveGroupDialog` takes a record type, the tree
  store has `moveNote` and `dropItem` (replaces `dropGroup`, 0.31), note rows
  are drag handles (0.30) and can be renamed in the tree (`updateNote{title}`).
