# 0.8 Validation error format

- Decided by: earlier sessions (moved from TODO.md section 0)

Same as the original (and zod's own
`ZodError.message`): `message` is `JSON.stringify(issues)`, an array of
`{code, path, message}` with the schema's original messages. Lets the
frontend map errors to fields by `path`. The Go validation helper is
introduced in item 1 and used by every handler after it.
