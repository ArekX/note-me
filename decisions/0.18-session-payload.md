# 0.18 Session payload

- Decided by: Claude (TODO item 1 options)
- Date: 2026-10-19

- `/api/login`, `/api/session` and `/api/process-step` return `{user,
  permissions, required_steps}`. `user.onboarding_state` is an object (parsed
  in the repository), and `user` also carries `created_at` / `updated_at` so
  the reset page can tell a new user (`created_at === updated_at`).
- `requeststate.Session.OnboardingState` is dropped: the session row stays
  slim (0.4) and onboarding is read from the user row.
- The frontend uses the server's `permissions` for `can()` and settings
  access; `rbac.ts` stays for labels and dropdowns (`hasSettingsPermission`
  added).
- The frontend fetches `/api/session` once per page load (the guard; `App.vue`
  no longer calls it, concurrent calls share one request).
