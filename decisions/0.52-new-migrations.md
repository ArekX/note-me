# 0.52 Table changes through new migrations

- Decided by: user
- Date: 2026-10-19

From item 15 on, a table structure change is a new migration
(`make new-migration NAME=...`) instead of an edit of the existing SQL
files. Each change is still reviewed against `cmd/noteme-upgrade`, which
runs before the migrations on an original database and must leave it in a
state the new migration accepts (for example 0.49 deletes old passkeys
before the unique index on credential ids is created).
