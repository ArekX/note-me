# 0.2 Migration tracking table compatibility

- Decided by: earlier sessions (moved from TODO.md section 0)

Done as a separate
binary, `noteme-upgrade` (`cmd/noteme-upgrade`), run once on an original
database: rebuilds `migration(name, timestamp)` as `migration(name,
executed_at)` (ISO string to unix seconds), drops `migration_lock`, and
extracts `file.data` blobs to `FILES_LOCATION/<identifier>`. The server
and the migrator are unchanged and only accept the upgraded layout.
